Revenue cycle, end to end

An agent with — deterministic tools across — modules: coding and coverage, claim build and scrub, remittance and variance, denials and appeals, forecasting, compliance and audit. Every rule is a tested pure function — the model chooses which to run, it does not invent the answer.

Not for real PHI. Coding education, code and policy lookup, and de-identified or synthetic examples only. The agent is instructed to refuse real patient identifiers.
